# ABREUZZ1 Performance

Site estático de apresentação de serviços de otimização para PCs gamers.

## Arquivos
- `index.html` — estrutura e conteúdo
- `style.css` — visual responsivo
- `script.js` — menu mobile

## Antes de publicar
1. Troque o número do WhatsApp no link `https://wa.me/5500000000000` dentro do `index.html`.
2. Ajuste preços e serviços conforme o que você realmente oferece.
3. Adicione seus resultados reais de testes, sem prometer FPS fixo.
4. Use apenas ferramentas obtidas de fontes oficiais.
5. Se fizer atendimento remoto, defina claramente como o acesso será autorizado e encerrado.

## GitHub Pages
Envie os três arquivos para um repositório no GitHub e ative GitHub Pages nas configurações do repositório.
